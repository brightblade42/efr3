* EyeFR installer / launcher


  NOTE: This tool replace 2 ansible projects. It is part of the **Radical Simplicity** philosophy. We aim to minimize the number of different technologies used.

** Current phase-1 bootstrap flow

On a fresh machine, the current flow is:

1. Install =just= with the bootstrap script
   - =sudo ./scripts/bootstrap/install_just.sh=
   - this uses the official =just= installer and installs a pinned version by default
   - the install location and version can be configured in =eyefr.env=

2. Copy the example env file
   - =cp eyefr.env.example eyefr.env=

3. Adjust any needed values in =eyefr.env=

4. Install phase-1 prerequisites
   - =just install-prereqs=
   - use =just --dry-run install-prereqs= to preview the full flow without executing it

You can also run individual phase-1 steps with:

- =just setup-repos=
- =just update-system=
- =just setup-user=
- =just install-podman=
- =just install-distrobox=
- =just setup-nvidia=
- =just configure-gpu-access=
- =just verify-gpu-access=

  This tool 2 goals

  1. Install prerequisites and dependencies
  2. Install one or more versions of FR services


  This can be accomplished with 2 high-level flows
  1. install phase-1 prerequisites
  2. install FR services


** Prerequites / Dependency installation

*** Preparing the server for running FR services

Install and configure the server.
- enable rhel repositories
- update OS
- create / configure the service user
- install podman
- install distrobox
- optionally install nvidia drivers
- optionally configure gpu access for containers
- verify gpu access

**** Features
should be able run any command independently to step through the process manually.
shouldn't rerun commands that have already updated the state of the machine unless --force is provided


** Install FR Services


An embedded FS embedded in the installer binary contains the directory structure, the various config files and bash scripts
needed to manage the FR services

- create the application directory structure under a versioned name
- copy configuration files to proper directories
- copy the initial database files

Default location for FR services is /home/user/fr/app_version

**** Data installation

 There are 2 postgres databases to install. The initial databases are embedded in the binary as tar files.
 They are extracted to the data folder and loaded as host volumes to their respective containers.

 We'll need to figure out if we need to do something like migrations for further sql updates. I really don't like migrations.
